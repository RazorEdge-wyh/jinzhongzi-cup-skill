# 04 · 论文 / 研究报告写作速查（操作版）

> 本文件是**操作速查**；逐条国标原文、官方实例与核实状态见 `08-paper-standards-verified.md`（20 个权威来源，逐条标 `[核实]`）。
> 标准依据：GB/T 7714—2015（参考文献）、GB 7713—87（编写格式）、GB 6447—86（文摘）、GB/T 15835—2011（数字）、GB 3100/3101/3102（量和单位）、GB/T 15834—2011（标点）；期刊细则以《中国农业科学》征稿简则等目标刊物要求优先。
> 长文本写作前先读 `08` 的对应节；本文件只给"做什么/别做什么"。

## 1. 先分清体裁

| | 研究报告（给评委/投资看） | 学术论文（投稿/毕设） |
|---|---|---|
| 目的 | 证明"这事能成、值得投" | 证明"这个发现可靠、可复现" |
| 结构 | 问题—方案—验证—价值—落地 | 引言—方法—结果—讨论—结论 |
| 篇幅 | 10–25 页 | 按期刊/学校要求 |
| 证据 | 关键数据 + 佐证材料 | 完整数据 + 统计 + 可复现细节 |
| 常见错误 | 写成论文，创业要素缺失 | 写成报告，方法与统计缺失 |

本项目的建议：**BP 里的"验证"章**用报告体；**真要投稿或毕设**用论文体。两者共用同一套数据与口径（`02-project-logic.md` §4）。

## 2. IMRaD 结构与每节写什么

### 2.1 标题

- 结构：`对象 + 处理 + 结果指向`。例：`定殖窗口期微灌对设施草莓根际枯草芽孢杆菌存活的影响`
- 不用"研究/初探/浅析"堆砌；不出现未定义缩写；≤25 个汉字为宜（按目标刊物要求）。

### 2.2 摘要（中文 200–300 字；结构式摘要按刊物要求可到千字）

四要素 + 四条硬约束：

```
目的：为解决<问题>，本研究<做了什么>。
方法：以<材料/地点/设计>，设置<处理与对照>，测定<指标>，采用<统计方法>分析。
结果：<关键数字，带单位与显著性>。
结论：<能推广到什么范围>，<局限>。
```

- **第三人称**：写"对……进行了研究""报告了……现状"，**不用"本文""作者"作主语**。
- **不分段、不加评论、不用图表、不用未定义缩写**。
- 农业类期刊常要求【目的】【方法】【结果】【结论】四个显式标识（中英对照）。
- 关键词 3–8 个（学位论文常 3–5），中英一一对应，不能只是缩写。

### 2.3 引言（三段式 + 农业期刊四要素）

1. 研究意义（为什么要做）。
2. 前人研究进展（引 3–5 篇高质量文献，含近 3 年；国外文献不可忽略）。
3. 本研究的切入点 + 拟解决的关键问题（缺口必须能被本研究填补），并明确写出假设。

农业类期刊（如《中国农业科学》）要求按【研究意义】→【前人研究进展】→【本研究切入点】→【拟解决的关键问题】顺序展开；引言不得与摘要雷同，不赘述教科书知识。

### 2.4 材料与方法（可复现是唯一标准）

必须写清 9 项：试验时间与地点；材料与条件的代表性及具体名称；试验规模（样本容量）；设计思路；设计方法；**重复次数**；仪器药品及规格；**统计方法**；借鉴他人方法给文献。

补充必填：

- 试验地：经纬度/海拔、土壤类型与基础理化、前茬、大棚类型。
- 材料：草莓品种、苗龄、菌株编号与来源、菌剂剂型与含菌量、蔗糖等级。
- 设计：处理数（含对照 CK）、重复数、小区面积（长×宽、行株距）、随机区组排列、缓冲行。
- 设备：传感器型号与标定方法、埋深、采样频率、阈值、单次水量上限、最小间隔。
- 测定：活菌数（稀释涂布平板法：培养基、温度、时间、3 重复）、死苗率、土壤含水率、产量与品质。
- 统计：软件与版本、检验方法、**多重比较方法名**、显著性水平。

**重复数不要随口写"3 次重复"**：农业田间试验常用 3 次，但重复数应保证误差自由度 df_e ≥ 12（最好 > 20）。随机区组单因素 `r ≥ (k+11)/(k−1)`（k 为含对照的处理数）；k=7~12 时 r≥3 才成立，处理少时必须加重复；计算"只入不舍"。

### 2.5 结果（只陈述，不解释）

- 按"图/表 + 一句话结论"组织，每个结果对应一个科学问题。
- 数字写法：`均值 ± SD（n=3）`，注明误差类型与 n；显著性用不同小写字母（肩标上角标）或星号，并在表注/图注解释。
- **不对他人研究做评述**（评述留给讨论）；不写"可能是因为…"。

### 2.6 讨论（四段）

1. 主要发现复述（不重复结果细节）。
2. 与已有研究比较（一致/不一致及原因）。
3. 机制解释（本项目：水分胁迫是早期死亡主因？糖信号趋根效应？）。
4. 局限与展望（作物单一、周期短、未测产量、传感器精度、样本量）——**主动写局限是可信度加分项**。

### 2.7 结论

3–5 条，每条一句话，只写本研究能支撑的；不外推。**禁用评论性套话**："奠定了基础""提供了保障""具有重要意义"。

## 3. 图表规范（农业类期刊的硬要求）

| 项 | 要求 |
|---|---|
| 表 | **三线表**（顶线/栏目线/底线），无竖线；必要时卧排；转页注"续表"并重复表头 |
| 题注 | **表题在表上方**居中；**图题在图下方**居中；图表须自明（不读正文可懂） |
| 中英对照 | 中文期刊通行：图题/表题/图注/表注/表内项目栏需英文对照（表内中文在上、英文在下） |
| 单位 | 量与单位写"量/单位"（前斜后正），如 `t/min`；全表同单位时提公共单位放右上角 |
| 坐标轴 | 标注"量、符号、单位"三者；刻度线向内 |
| 有效数字 | 同栏上下对齐、同一指标有效位数一致；修约依 GB 8170 |
| 误差 | 必须写明 `±SD` 还是 `±SE`，并在注中给 n |
| 显著性（字母法） | 小写字母作**上角标**标在平均值处；表注固定写法："同列数据肩标小写字母不同表示差异显著（P<0.05），小写字母相同表示差异不显著（P>0.05）" |
| 显著性（星号法） | `*`P<0.05、`**`P<0.01、`***`P<0.001，图注给定义；**星号宜限图，表内避免**（防与数学符号混） |
| 空缺值 | 空白=未测/无此项；"—/…"=未发现（不用"-"，防与阴性混淆）；0=实测为零；不得用"同上""同左""″" |
| 编号 | 图 1、表 1 或分章编号（图 1-1），全文统一；附录图表冠 A（图 A1） |
| 地图 | 涉国界必须用自然资源部标准地图底图，注审图号，用线段比例尺 |
| 正斜体 | 物理量符号斜体、单位正体、向量黑斜体；生物学名拉丁文斜体；*t*、*F*、*P*、*r*、*χ*² 斜体 |
| 分辨率 | 位图 ≥300 dpi（线条图 ≥600 dpi）；导出 TIFF/PNG，不用截图；颜色灰度打印可辨 |

**本项目的关键图**：①定殖密度-时间曲线（对数纵轴，窗口底色）②处理组间第 7/15 天活菌数柱状图（误差棒 + 字母标）③双时间轴（活菌 vs 缓苗/花芽分化）④装置示意与布点图。

## 4. 参考文献：GB/T 7714—2015 顺序编码制

### 4.1 正文标注

- 按引用先后连续编号，方括号**上标**：`…显著提高产量[1]。`
- 同一处引多篇：`[1-3]`、`[1,4]`；同一文献多处引用用同一序号。
- **多次引用同一文献时，页码置于方括号之外**：`…反对者[2]260`、`[2]326-329`。
- 作者作句子成分：`张三等[2]发现…`；英文 `Smith et al.[3] reported…`。
- 顺序编码制与著者—出版年制**选一种贯穿全文**，不得混用。

### 4.2 文末著录模板（照此填，标点全用半角）

| 类型 | 格式 | 示例 |

**本条目的标准（易错）**：GB/T 7714—2015 的"标准"著录是**责任者. 标准名称: 标准号[S]…**，不是旧版的"标准号在前"。正确的 NY/T 3428 条目应为：
`农业农村部. 草莓绿色生产技术规程: NY/T 3428—2019[S]. 北京: 中国农业出版社, 2019.`

### 4.3 作者与细节规则

- 中文：3 名以内全列；**超过 3 名列前 3 名后加"，等"**。英文：超过 3 名列前 3 名后加", et al."。
- 姓名：一律姓前名后；汉语拼音名"姓全大写、名缩写"（LI J N）。
- 组织作者用全称；责任者不明著录"佚名"。
- 页码：阅读型著录起讫页；引文型著录所引信息页；可写"序 2-3"。
- **DOI 是电子资源的必备项**，置于访问路径后：`DOI:10.xxxx/xxxx.`。
- 标点全半角：`,` `.` `;` `()` `[]` `//` `-`；每条以"."收尾。
- 双语著录：先原语种后其他语种（中文期刊常要求中文条目英译，英文不另编号）。

### 4.4 常见错误

- 期刊缺卷期/页码；学位论文缺出版地；标准格式用旧版"标准号在前"；网页缺引用日期；DOI 缺失。
- 4 位以上作者仍全列（应前 3 + 等）。
- 正文序号未上标；多次引用未在方括号外补页码。
- 同一文献两个序号；转引未标"转引自"；正文与文末不一一对应（幽灵引用/缺失引用）。

## 5. 中文写作规范

### 5.1 数字（GB/T 15835）

- 计量、统计、编号用阿拉伯数字；概数、成语、名称用汉字（"三四个""十四五"）。
- 年份不简写（`1990 年`，不写"90 年"）；日期 `1994-09-30`，月日补 0。
- 多位整数/小数**每三位一组、组间空 1/4 汉字位，不用千位撇**：`2 748 456`、`3.141 592 65`；纯小数补 0（`0.314`）。
- 数值范围用"～"（`63%～68%`），不混用"-"。
- 同一段落/同一组数据内体例一致。

### 5.2 量和单位（GB 3100/3101/3102）

- 量的符号斜体（pH 例外），单位符号正体。
- 数字与单位间空半字间隙：`150 元`、`10 cm`、`5 mmol/L`、`3 d`。
- 农业面积换算为公顷（hm²）。
- 常见写法：`(23.1±1.6) kg`、`(3.2±0.2)%`、`8×10⁶ cfu`、`1 200 r/min`、`650～1 100 ℃`。
- 单位符号不得加修饰词（不写 `/kg 体重`）。

### 5.3 标点（GB/T 15834）

- 正文中文用全角；科技文献句号可用小圆点"."；参考文献条目内用半角。
- 顿号用于并列词语（`寒、温、热三带`）；书名号之间不加顿号。

### 5.4 术语与表述

- 全文统一：定殖（菌）/定植（苗）、菌株/菌剂、根际/根圈、"定殖窗口/0–30 天"。
- 用"已/将/拟"区分已做与计划；"相关"不写"导致"。
- "国际领先/填补空白/首次"须有查新或专利支撑，否则删。
- 首次出现的缩写给全称；标题与摘要避免未定义缩写。

## 6. AI 使用与学术诚信（有据可依）

### 6.1 AI 声明（依《学术出版中 AIGC 使用边界指南》）

- AIGC **不得列为作者**（无法律地位、不能负责）。
- 使用 AIGC 须在**方法或致谢**处公开、透明、详细说明，披露 5 要素：使用者；工具/系统名称**及版本号**；使用时间；使用目的；AIGC 生成/共同生成的部分与所依据的提示。
- 推荐声明模板：`在本作品的准备过程中，作者使用了[工具名/版本]来[目的：文献调研/数据分析/图表制作/语言润色]。使用后作者对内容进行了审查与编辑，并对出版物内容承担全部责任。`
- **未声明 AIGC 直接生成的稿件文字可能构成抄袭**；AIGC 提供的参考文献**必须逐条人工核验**（可能虚构）。
- AIGC 可用于统计分析的辅助，但**数据必须由研究者自己采集**，统计结果须复算。

### 6.2 学术不端的法定类型（教育部令第 40 号 第二十七条）

1. 剽窃、抄袭、侵占他人学术成果；
2. 篡改他人研究成果；
3. 伪造科研数据、资料、文献、注释，或捏造事实、编造虚假研究成果；
4. 未参加研究/创作而署名、不当使用他人署名、虚构合作者、未注明他人贡献；
5. 在申报课题、成果、奖励、职务评审、**申请学位**等过程中提供虚假学术信息；
6. 买卖论文、由他人代写或为他人代写；
7. 其他依高校/学术组织规则属于学术不端的行为。

《学位法》（2025-01-01 施行）第三十七条：学位论文或实践成果存在**代写、剽窃、伪造**等学术不端，可**不授予或撤销学位**。

### 6.3 "自我抄袭"的边界（CY/T 174—2019）

- **重复发表** = 未说明的情况下重复发表自己（或作为作者之一）已发表文献的内容。**边界在"是否说明"**：说明并规范引用即不构成，不说明即构成。
- **洗稿也算剽窃**：不加引注、不变本意地转述（改句式、同义替换）属文字表述剽窃。
- 数据剽窃包含"改变数据呈现方式后不加引注"（图表↔文字互转）。
- 成段使用他人文字，即使加了引注，**未加引号/未做区分**仍可能被认定剽窃。

## 7. 投稿/提交前自检（论文版）

- [ ] 引言有缺口与假设；农业类期刊按四要素展开
- [ ] 方法 9 项齐全；重复数有依据（df_e≥12），写明多重比较方法名
- [ ] 结果不解释、讨论不重复结果、结论无套话
- [ ] 图表三线表、题注位置、中英对照、公共单位、误差类型、n、显著性标注齐全
- [ ] 引用与文末双向一一对应；标准/学位论文/网页格式按 4.2；DOI 不缺失
- [ ] 作者>3 用"等"；多次引用页码在方括号外
- [ ] 数字/单位/标点符合 GB/T 15835、GB 3100~3102、GB/T 15834
- [ ] 局限与展望独立成段；无"国际领先/奠定了基础"类表述
- [ ] AI 使用已按要求声明；AI 给的文献已逐条核验
