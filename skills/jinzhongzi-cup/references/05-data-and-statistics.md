# 05 · 数据、试验设计与统计

> 用途：本项目所有"效果"主张的底层方法论。评委/审稿人只问三件事：**对照组对不对、重复够不够、统计方法选对没有**。
> 目标：用最少的试验获得可辩护的结论，并让第二位研究者能按方案重做。

## 1. 试验设计（第一轮盆栽/台架 → 第二轮田间）

### 1.1 处理设置（四组，能同时回答四个问题）

| 组 | 处理 | 回答什么问题 |
|---|---|---|
| T1 触发组 | 接菌 + 窗口期按双条件触发微灌 | 本项目方案是否有效 |
| T2 常规接菌组 | 接菌 + 常规灌溉（不触发） | 效果是否来自"触发"而不是"接菌" |
| T3 空白组 | 不接菌 + 常规灌溉 | 本底水平、菌的净贡献 |
| T4 补施组（可选但强烈建议） | 接菌 + 窗口后补施一次菌剂 | 与"最省事的替代方案"比，本项目是否更划算 |

**T4 是评委最爱问的对照**（"为什么不直接补施？"）。第一轮没条件做可以省，但方案里必须写"第二阶段纳入"。

### 1.2 小区与重复

- 盆栽/台架：每处理 ≥3 个独立盆/槽（独立单元，不共享水肥），完全随机排列；建议 4–5 重复以提高功效。
- 田间：随机区组（RCBD），≥3 区组；每小区 ≥20 株；小区间设 ≥1 行缓冲行防止水肥串流。
- **重复数要有依据，不是随口写"3 次重复"**：约束是误差自由度 df_e ≥ 12（最好 > 20）。单因素随机区组 `r ≥ (k+11)/(k−1)`（k 为**含对照 CK** 的处理数）；k=7~12 时 r≥3 才成立，处理数少时必须加重复；小数"只入不舍"（2.3 取 3）。本项目 4 个处理（含 CK）→ r≥5 才稳；条件有限时可先 r=3，但要在论文里承认功效不足。
- **重复的单位是小区/盆，不是同一小区里的取样点**。同一小区取 5 点混合成 1 个样，n = 小区数。这是最常见的伪重复错误。
- 取样点位置固定标记，避免"哪好取哪"。
- 行业标准参照：**NY/T 1536—2025《微生物肥料田间试验与效果评价技术规程》**（2025-01-09 发布、2025-05-01 实施，代替 NY/T 1536—2007）规定了微生物肥料田间试验设计与效果评价流程。本项目的试验方案应与其框架对齐（处理设置、重复、测定指标、效果评价），并在方案里引用该标准号。`[条文细节未核：该标准 PDF 字体缺 ToUnicode，仅封面可读]`

### 1.3 时间点

| 时点 | 目的 |
|---|---|
| 第 0 天（处理前） | 基线，证明组间初始一致 |
| 第 7 天 | 早期存活，核心判定点之一 |
| 第 15 天 | 核心判定点之二 |
| 第 30 天 | 窗口末端，看衰减与回落 |
| 收获期 | 产量/品质（第二阶段） |

### 1.4 记录（原始数据要能自证）

- 每小区一张田间记录卡：处理编号、区组、株数、每次触发时间与水量、传感器读数、异常事件（断电、漏水、病害）。
- 原始记录**纸质 + 照片**，数据录入后保留原始表，不做"整理后即弃"。
- 设备日志（ESP32 串口/SD 卡）按小区保存，作为"触发确实发生"的客观证据——这是本项目最硬的证据类型。

## 2. 活菌数测定（核心指标的测量质量决定项目可信度）

1. 取样：每小区随机 5 株，抖根法取根际土（附着于根表 1–2 mm），混合为 1 个复合样，冰盒 4 °C 运输，24 h 内处理。
2. 稀释：10 g 鲜土 + 90 mL 无菌水（含 0.1% 吐温 80 或生理盐水），振荡 30 min，10 倍梯度稀释至 10⁻⁵–10⁻⁷。
3. 涂布：每个稀释度 3 个平板，每板 0.1 mL；选择性培养基或含抗生素标记（若菌株带 GFP/抗性，见 F5 的方法思路），28–30 °C 培养 24–48 h。
4. 计数：30–300 CFU/板的平板才有效；取 3 板均值；结果换算为 **CFU/g 鲜土**，同时测土壤含水率以便换算干土基数（**口径必须固定一种并全文一致**）。
5. 对照：无菌水涂布作污染对照；必要时做菌落形态/PCR 确认，避免把土著菌计入。
6. 记录：稀释度、平板数、培养条件、原始计数、换算公式。

> 若无法用选择性培养基区分目标菌与土著芽孢杆菌，必须在论文/报告中明确说明这一局限，并考虑 GFP 标记、qPCR 或特异性引物作为替代/补充方法。

## 3. 统计方法选择（决策树）

```
数据是否近似正态 + 方差齐？
├─ 是（或变换后是）
│   ├─ 两组比较 → 独立样本 t 检验（Welch 校正用于方差不齐）
│   └─ 多组比较 → 单因素 ANOVA + 多重比较（**Tukey HSD 或 PLSD**；方法名必须写进方法节）
│        └─ 有区组 → 双因素 ANOVA（处理 × 区组）
└─ 否（变换后仍不正态）
    ├─ 两组 → Mann-Whitney U
    └─ 多组 → Kruskal-Wallis + Dunn 事后检验
```

> 关于多重比较：SSR 法（Duncan 新复极差法）的统计基础已受质疑，原作者亦不再坚持；建议改用 **PLSD**（保护最小显著差数法：先要求处理项 F 检验显著，再做 LSD）。详见 `08-paper-standards-verified.md` §4（S10 刘义满 1999）。

- 活菌数通常跨数量级：**先取 lg 变换**再检验（论文里注明"数据经 lg 转换后分析"）。
- 百分率（死苗率）接近 0 或 100% 时，用 arcsine 变换或改用广义线性模型（二项分布）。
- 多时点数据不要逐时点反复 t 检验（多重比较膨胀），用重复测量 ANOVA 或混合效应模型（时点 × 处理）。
- 显著水平统一 α=0.05；报告**精确 P 值**（P=0.032），不写 P<0.05 了事；P=0.051 也要如实写。
- 报告格式：`均值 ± 标准差（n=3）`；表下注明"同列不同小写字母表示差异显著（P<0.05，Tukey HSD）"。

## 4. 统计错误自查（逐条对照，命中即改）

| 错误 | 表现 | 正确做法 |
|---|---|---|
| 伪重复 | n=15 其实是 3 小区 × 5 点 | n = 小区数；点作为混合样 |
| 无对照 | 只测处理组 | 至少 T2/T3 |
| 只做一次 | n=1 就下结论 | ≥3 重复，重复试验 |
| 事后挑时点 | 测 5 个时点只报显著的 | 预注册主判定时点（第 7/15 天） |
| P-hacking | 反复换检验直到 P<0.05 | 先定方法，写进方案 |
| 相关当因果 | "活菌数高所以增产" | 写"相关"，或补机制/剂量试验 |
| 只报均值 | 无变异信息 | 均值 ± SD + n |
| 忽略区组 | 田间数据当完全随机 | RCBD 双因素分析 |
| 图表打架 | 图与表数字不一致 | 同一数据源生成，交付前对表 |
| 单位混乱 | CFU/g 与 CFU/g 干土混用 | 锁定一种口径并注明 |

## 6. 数据管理

- 原始数据（Excel/CSV）与设备日志放同一目录，命名 `菌护禾_原始数据_YYYYMMDD_vN.xlsx`。
- 每次修改另存版本，不覆盖；分析脚本（Python/R）与数据放一起，保证可重跑。
- 备份 ≥2 处（本地 + 云/移动硬盘）。
- 对外提供（BP 附件/论文附录）时，给"脱敏后的汇总数据 + 原始数据可应要求提供"。
- 保留期限：项目结束后至少 5 年（应对质疑/复核）。

## 7. 两阶段验证路线（与 BP 的"里程碑"对齐）

| 阶段 | 时间 | 设计 | 判定 | 失败应对 |
|---|---|---|---|---|
| P0 台架 | 11 月 | 盆栽 4 处理 × 3 重复，控温控湿箱/温室 | 触发组第 7 天活菌数显著高于 T2 | 调阈值/检查传感器标定 |
| P1 温室/小棚 | 12 月–次年 2 月 | 随机区组，3 区组，加 T4 补施组 | 第 7/15 天均显著 + 死苗率下降 | 收窄作物/场景，改叙事为"技术验证" |
| P2 田间示范 | 次年 3–5 月 | ≥3 户示范田 + 对照田 | 活菌数 + 死苗率 + 产量趋势 | 用趋势与用户反馈支撑，不承诺产量 |

**每一阶段结束都要更新 BP 的"验证结果"章与财务假设**——评委看的是"有没有在推进"，不是"一步到位"。
