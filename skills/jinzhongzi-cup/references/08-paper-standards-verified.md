## 1. 参考文献著录：GB/T 7714—2015

### 1.1 规则要点（checklist）

- [ ] **选一种制度并贯穿全文**：`顺序编码制` 或 `著者—出版年制`；文内标注与文后条目必须对应，不得混用。`[核实 S2]`
- [ ] **顺序编码制标注**：按正文首次出现先后连续编号，序号置于**方括号并上标**，如 `[1]`、`[2]`；同一处引多篇用逗号分隔，连续序号用短横线，如 `[70,83]`、`[255-256]`。`[核实 S2]`
- [ ] **多次引用同一文献**：正文只标首次序号，并在方括号**之外**著录引文页码，如 `……坚决反对者[2]260`、`[2]326-329`。`[核实 S2]`
- [ ] **文献类型标识**：M 专著、J 期刊、D 学位论文、C 论文集、N 报纸、R 报告、S 标准、P 专利；载体标识 OL（联机）、CD、MT、DK；2015 版新增 A 档案、CM 舆图、DS 数据集、Z 其他。`[核实 S18]`
- [ ] **作者著录**：3 人及以下**全部列出**，用逗号分隔；**3 人以上只著录前 3 人，其后加"，等"**；外文加", et al."（et al. 不加斜体）。`[核实 S2、S19、S8]`
- [ ] **姓名顺序**：一律姓前名后；用汉语拼音书写的人名，**姓全大写、名可缩写取首字母**（依 GB/T 28039—2011），如 LI J N。`[核实 S18、S5]`
- [ ] **机构作者**用全称不用简称；责任者不明著录"佚名"。`[核实 S2]`
- [ ] **页码**：阅读型参考文献著录起讫页或起始页；**引文参考文献著录引用信息所在页**；引自序言/扉页题词可按实际著录（如"序 2-3"）。`[核实 S18]`
- [ ] **DOI**：电子资源的"数字对象唯一标识符"为**必备项**，著录于获取和访问路径之后，形式 `DOI:10.xxxx/xxxx.`。`[核实 S18、S11 示例]`
- [ ] **著录文字**：可双语著录——**先原语种、后其他语种**；《中国农业科学》要求中文条目译成英文，先中文后英文，英文不另编号。`[核实 S18、S5]`
- [ ] **标点**：全部用**半角英文符号**，每条以"."收尾；";"用于年卷期中的年与卷，"()"用于期号、报纸版次、引用日期，"[]"用于序号与文献类型，"//"用于专著析出文献出处，"-"用于起讫页码。`[核实 S2、S5]`
- [ ] **数量**：《中国农业科学》研究报告参考文献**不低于 30 篇**、综述**不低于 50 篇**，优先近 5 年与同行评议期刊，不引未公开资料；《森林工程》不少于 17 篇。`[核实 S5、S8]`

## 2. 论文结构：IMRaD 与中文学位论文/期刊结构

### 2.1 规则要点（checklist）

- [ ] **国标主体结构**：引言（或绪论）→ 正文（材料、方法、结果）→ 结论或讨论；主体"由另页右页开始"。`[核实 S3 §6.1]`
- [ ] **引言**写：研究工作的目的、范围、相关领域前人工作与知识空白、理论基础与分析、研究设想、方法与实验设计、预期结果和意义；**不得与摘要雷同，不得成为摘要的注释，不赘述教科书知识**。`[核实 S3 §6.3]`
- [ ] **中文农业期刊的"五段式"**（与 IMRaD 的对应关系）：`0 引言` → `1 材料与方法`(=M) → `2 结果`(=R) → `3 讨论`(=D) → `4 结论`(=C)。`[核实 S5 §2]`
- [ ] **引言四要素**（《中国农业科学》硬性要求，按此顺序展开）：【研究意义】→【前人研究进展】→【本研究切入点】→【拟解决的关键问题】；国外文献不可忽略，近期文献占相当比例。`[核实 S5 §8]`
- [ ] **讨论单独成段，不与结果或结论混写**：比较本研究与前人的异同，说明验证/否定/证实了什么，解释机制，分析不一致之处。`[核实 S5 §13]`
- [ ] **结论单独成段**：高度简明、有实际内容、条理清晰，把基本信息全部展示以便他人引用；**禁止"奠定了基础""提供了保障"等评论性语言**。`[核实 S5 §14]`
- [ ] **结果部分一般不对他人研究进行评述**（评述留给讨论）。`[核实 S5 §10]`
- [ ] **学位论文结构**（区别于期刊论文）：封面 → 原创性声明及授权使用声明 → 摘要 → 目录（含图表目录）→ 符号说明 → 正文（绪论独立成章）→ 参考文献 → 附录 → 致谢 → 作者简历及成果；**绪论须独立成章、用足够文字，不与摘要雷同**；标题最多编到三级（1.1.1）。`[核实 S2]`
- [ ] **章节编号**：层次以少为宜，最多四级；数字间用小圆点，末位不加点，如 1.1、1.1.1。`[核实 S2]`

### 2.2 摘要（Abstract）

- [ ] **四要素**：目的 — 方法 — 结果 — 结论（GB 6447—86 §5 明列"目的/方法/结果/结论/其他"）。`[核实 S4]`
- [ ] **独立性/自含性**：不读全文即可获得必要信息；有数据、有结论；可独立引用、可供二次文献采用。`[核实 S3 §5.7.3]`
- [ ] **写法**：客观如实，**不加评论与主观见解**；**不分段落**；**用第三人称**（"对……进行了研究""报告了……现状"），**不用"本文""作者"作主语**；除非证实或否定他人著作，**不用引文**；用法定计量单位。`[核实 S4 §6.1–6.13]`
- [ ] **不用图表**：摘要中不用图、表、化学结构式、非公知公用符号。`[核实 S3 §5.7.5]`
- [ ] **长度取值**：GB 7713 中文摘要 200~300 字；GB 6447 报道性文摘 400 字左右、指示性 200 字左右；《中国农业科学》用**结构式长摘要、千字左右**；《森林工程》300 字左右。**按目标刊物定，不要照搬国标数值**。`[核实 S3、S4、S5、S8]`
- [ ] **结构式摘要（中文期刊高频要求）**：必须保留【目的】【方法】【结果】【结论】四个标识，英文对应【Objective】【Method】【Result】【Conclusion】，各要素用完整语句。`[核实 S5 §6]`

### 2.3 关键词

- [ ] **数量**：GB 7713 规定 **3~8 个**，另起一行排在摘要左下方；学位论文常用 3~5 个（S2）；部分期刊要求 5~8 个（S8、S7）。`[核实 S3 §5.8、S2、S8]`
- [ ] 中文关键词之间用中文逗号/分号，英文关键词首字母大写、用英文逗号；**英文关键词须与中文一一对应**。`[核实 S2]`
- [ ] 不选与专业内容关系不大的非专业词；**不能只是英文缩写，须有对应中文**。`[核实 S7]`

### 2.4 基金标注与作者简介

- [ ] **基金项目**：首页脚注注明基金项目**名称 + 括号内项目编号**；无任何项目资助的稿件，"除非具有重大学术价值，原则上不予受理"。`[核实 S5 §7]`
- [ ] 无编号时须注明"无编号"；多个项目用分号分隔。`[核实 S7]`
- [ ] **作者简介**（首页脚注）：第一作者姓名、出生年、性别、职称、学历、研究方向、E-mail；**通信作者**另注。`[核实 S5 §7、S7、S8]`
- [ ] 署名限于"参加研究工作并可解答论文有关问题者"；作者顺序一经录用原则上不再调整。`[核实 S5 §4]`
- [ ] 汉语姓名译法：正文标题下**姓全大写、名首字母大写、双名连写不空格**（ZHAI HuQu）；参考文献中则"姓首字母大写 + 名缩写"（Zhai H Q）。`[核实 S5 §5]`

## 3. 图表规范

### 3.1 规则要点（checklist）

- [ ] **表格一律用三线表**，避免竖线；不得用过大的表，必要时卧排（"顶左底右"）；转页须在续表表头上方注"续表"并重复表头。`[核实 S2、S7、S9、S3]`
- [ ] **表题在表上、图题在图下**：每一表应有简短确切题名**连同表序置于表上居中**；每一图应有简短确切题名**连同图序置于图下居中**。`[核实 S3 §6.4.1/6.4.2、S2]`
- [ ] **自明性**：只看图/表、图题/表题和注释，不读正文即可理解。`[核实 S3]`
- [ ] **图表必须中英文对照**（中文期刊通行要求）：图题、表题、图注、表注、表中项目栏均需英文对照；表内项目栏中文在上、英文在下。`[核实 S5 §11、S8]`
- [ ] **表注横排于表下**（表题"下"或表"下"，各刊略有差异，以模板为准）；表注五号字、1.25 倍行距。`[核实 S3、S2]`

## 4. 统计与试验报告规范

### 4.1 规则要点（checklist）

- [ ] **材料与方法必须写清 9 项**：试验时间、地点；试验材料与条件的代表性及具体名称；试验规模（**样本容量**）；设计思路；设计方法；**重复次数**；仪器、药品及规格；**统计方法**；借鉴他人方法须给文献。`[核实 S5 §9]`
- [ ] **随机区组设计的最低重复数**（保证误差自由度 df_e ≥ 12，最好 > 20）：
  - 单因素随机区组：`r ≥ (k+11)/(k−1)`；双因素：`r ≥ (ab+11)/(ab−1)`；三因素：`r ≥ (abc+11)/(abc−1)`
  - 完全随机（各处理重复相等）：`r ≥ (k+12)/k`
  - 常用查表：k=3 → r≥7；k=4 → r≥5；k=5 → r≥4；k=6 → r≥4；7≤k≤12 → r≥3；k≥13 → r≥2
  - 计算重复数**"只入不舍"**（2.3、2.6 均取 3），不得四舍五入。`[核实 S10]`
- [ ] **"3 次重复"的定位**：3 次重复是农业田间试验的**最常见做法**（一项 30 份试验报告的调查中 80% 为 3 次重复），但**它只是满足 df_e≥12 的下限条件之一**（处理数 7~12 时 r≥3 成立），处理数少时必须增加重复。**不要把"3 次重复"当成万能及格线**。`[核实 S10]`
- [ ] **必须设置对照（CK）**，并在处理数 k 中计入对照。`[核实 S10 公式中"处理数 k（包括对照）"]`
- [ ] **检验方法的选择与交代**：
  - 两处理比较 → *t* 检验；多处理单因素 → 单因素方差分析 + 多重比较；多因素/互作 → 多因素方差分析。`[核实 S7"F 检验"、S9；具体选择规则为通用统计学，[未核实]]`
  - 多重比较**必须在方法中注明具体方法名**（该调查中 73.3% 的报告未注明，属硬伤）。
  - **SSR 法（Duncan 新复极差法）统计基础已受质疑**，原作者本人亦不再坚持；**建议改用 PLSD 法（保护最小显著差数法，即在 LSD 前加"处理项 F 测验显著"这一前提）**。`[核实 S10 §2.2]`
- [ ] **P 值表述统一**：`P<0.05` 差异显著、`P<0.01` 差异极显著、`P>0.05` 差异不显著；同篇内阈值不得混用 0.05/0.01 而不声明。`[核实 S7]`
- [ ] **统计符号正斜体**（GB 3358）：*t* 检验用英文小写斜体 *t*，*F* 检验用大写斜体 *F*，卡方用希腊大写斜体 *χ*²，相关系数用英文小写斜体 *r*，概率用大写斜体 *P*。`[核实 S7 引 GB 3358—82；现行版本为 GB/T 3358.1—2009，标准号替换 [未核实]]`
- [ ] **术语不得混用**：区分"因素 / 水平 / 水平组合 / 处理"；不要用"随机排列"代替具体设计名（随机排列下含完全随机、随机区组、拉丁方、裂区、条区等）；小区面积须交代长宽、行距、株距。`[核实 S10 §2.3]`
- [ ] **百分数**：说明是否做过数据转换（如反正弦/平方根转换）；百分数范围写作 `63%～68%`。`[核实 S10、S15]`
- [ ] **"相关不等于因果"**：报告相关系数只能陈述"相关/关联"，不得写"导致""引起""决定"。`[未核实]`（未抓到直接规范条文；属统计学共识，建议在 skill 中作为写作禁令保留）
- [ ] **田间试验报告要点汇总**（可直接做 checklist）：试验地点与年份 → 土壤/气候背景 → 供试材料与来源 → 试验因素与水平（含 CK）→ 小区面积与排列 → 重复次数与设计方法 → 播种/施肥/管理措施 → 测定项目与方法（含仪器）→ 统计方法与软件 → 显著性水平。`[核实 S5 §9 与 S10 §2.3 合并]`
- [ ] **农业行业标准参照**：NY/T 1536—2025《微生物肥料田间试验与效果评价技术规程》（2025-01-09 发布、2025-05-01 实施，代替 NY/T 1536—2007）规定了田间试验设计与效果评价的技术流程。**正文细节因 PDF 字体编码损坏未能提取，仅封面信息可核**。`[核实 S20 封面；条文内容 [未核实]]`

## 6. 中文写作规范（数字、量与单位、标点）

### 6.1 数字用法：GB/T 15835

- [ ] **必须用阿拉伯数字**：统计表中的数值（正负整数、小数、百分比、分数、比例）。所以 `34.05%`、`63%～68%`、`1/4`、`1:500` 均用阿拉伯数字。`[核实 S15 §4.1.1]`
- [ ] **必须用汉字**：定型的词、词组、成语、惯用语、缩略语或具修辞色彩词语中作语素的数字（一律、一方面、二倍体、三叶虫、星期五、四氧化三铁、八国联军、"八五"计划、五省一市、第三季度）。`[核实 S15 §4.1.2]`
- [ ] **物理量量值必须用阿拉伯数字**并正确使用法定计量单位：`8 736.80 km`、`100 kg～150 kg`、`34 ℃～39 ℃`、`400 mm×200 mm×300 mm`。`[核实 S15 §6]`
- [ ] **年份一般不简写**：`1990 年`不得写作"九Ｏ年"或"90 年"；年月日可用扩展格式 `1994-09-30`，月日个位数补 0。`[核实 S15 §5.1.1]`
- [ ] **多位整数与小数分节**：专业性科技出版物从小数点起向左向右每三位一组，**组间空 1/4 汉字位置，不用千位撇**：`2 748 456`、`3.141 592 65`；纯小数须在小数点前补 0（`0.314`，不写 `.314`）。`[核实 S15 §8.1.1；GB 7713 §6.4.3 同]`
- [ ] **全篇体例统一**：一至十的整数若不在一组有统计意义的数字中可用汉字（"三本书""六条意见"），但同一段落/同一组数据内须一致。`[核实 S15 §7.2]`
- [ ] 数值范围用"～"（波浪号），不混用"-"。`[核实 S15 示例、S7 示例]`

### 6.2 量和单位：GB 3100 / 3101 / 3102

- [ ] **国际单位制（SI）是我国法定计量单位的基础**，一切属 SI 的单位都是我国法定计量单位（GB 3100—93，等效采用 ISO 1000:1992，代替 GB 3100—86）。`[核实 S17 引言]`
