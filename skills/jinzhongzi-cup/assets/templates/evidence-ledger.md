# 证据台账（Evidence Ledger）

> 作用：把"材料里出现的每一个数字/结论"和"它的来源与核实状态"绑在一起。这是本 skill 的诚信底座——**没有台账条目的数字，不允许进材料**。
> 用法：每写一段材料，先把要用的断言登记到本表（状态填"待核实"），核实后改"已核实"并补题录；交付前检查"待核实/待实测"的数量，并在材料里如实标注。

## 字段说明

| 字段 | 含义 |
|---|---|
| ID | E01、E02…（材料正文可引用，如"（E01）"） |
| 断言 | 一句可直接用于材料的话，含数字与单位 |
| 类型 | 文献 / 标准 / 官方统计 / 本项目实验 / 用户访谈 / 供应商报价 / 假设 |
| 来源 | 作者. 题名. 出处. 年份；或"实验 EX-20261201-01 第 7 天数据"；或"XX 供应商 2026-11-05 报价单" |
| 可访问位置 | 文件路径 / URL / 原始记录编号 |
| 时点 | 数据对应的日期/时点（如第 7 天、2026-11） |
| 口径 | 单位与统计口径（如 CFU/g 鲜土，n=3，均值±SD） |
| 状态 | 已核实 / 待核实 / 待实测 / 假设 |
| 用在哪 | BP/PPT/论文的哪一节 |
| 风险 | 该来源可能的质疑点（样本小/单一作物/厂商数据…） |

## 交付前检查

- [ ] 表中"已核实"的行数 ≥ 材料中关键数字数
- [ ] 每条"待实测/待核实"在材料里都有对应标注（"待验证/文献值/目标值"）
- [ ] 没有材料里的数字在台账中缺席
- [ ] 文献类条目已补全题录（作者、年份、刊名、卷期页码）
- [ ] 报价类条目有截图/单据，且注明日期
- [ ] 实验类条目能追到原始记录编号

## 与材料的联动写法

- 已核实：正文正常写，脚注给来源；"已有研究表明…[1]"
- 待实测/目标值：写"目标为…（待第 7 天实测验证）"，不要写成"已达到"
- 假设：写"假设…，依据是…；该假设将在 X 阶段用 Y 方法验证"
- 用户口述：写"（据用户提供，待补佐证）"
