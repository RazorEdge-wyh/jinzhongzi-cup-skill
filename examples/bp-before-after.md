# BP 写作对比：AI 味版本 vs 去 AI 感版本

> 示例用途：同一段"痛点 + 方案"的两种写法。左边是典型的 agent 输出，右边是按本 skill 规则改后的版本。
> 文中数字为虚构示例。

## 1. 痛点段

### ❌ AI 味版本

```
**定位宣言：** 致力于成为设施农业微生物管理的引领者
**核心逻辑：** 以硬件为入口、以数据为壁垒、以服务为粘性

我们的产品通过先进的物联网技术，显著提升菌剂使用效果，有效解决行业痛点，
填补了国内空白，市场前景广阔，必将颠覆传统农业管理模式。
```

问题：
- 标签体三连（`定位宣言：`/`核心逻辑：`）；
- 无一个具体事实；
- "显著提升""有效解决""填补空白""前景广阔""必将颠覆"全是无证据最高级；
- 对仗金句（硬件为入口/数据为壁垒/服务为粘性）是模板味最重的句式。

### ✅ 去 AI 感版本

```
莓农买菌肥的钱，很多时候是白花的。

我们在长沙、湘潭走访的 12 户设施草莓种植户里，有 9 户提到"菌肥施下去看不出变化"。
他们每亩每季在菌肥上的投入大约 180 元，但死苗率与化肥用量并没有明显下降。
问题不一定是菌不好——已有研究显示，芽孢杆菌施入土壤后 1–2 周内定殖密度会下降
3–4 个数量级，而这段时间恰好是草莓缓苗、最需要菌起作用的时候。

我们做的事很小：在这 30 天里，当土壤偏干、温度又合适时，自动补一次小水，
让菌活到能干活的时候。窗口一过，装置就停。
```

为什么更好：
- 开头一句事实，不喊口号；
- 有地点、户数、金额、时间窗口；
- 用"已有研究显示"引出机制，而非自夸；
- 方案用一句人话讲清楚，不用表格堆功能。

## 2. 财务段

### ❌ AI 味版本

```
本项目盈利能力强，第一年营收 5000 万元，第三年突破 3 亿元，毛利率保持在 60% 以上，
具备良好的投资价值。
```

问题：无客户数、无单价、无推导、无假设，财务 20 分基本拿不到。

### ✅ 去 AI 感版本

```
收入按"服务点数 × 每亩服务费"推算。首年计划在长沙县、湘潭县各建 5 个示范点，
每点覆盖 0.2 亩，按 199 元/亩·季收费：10 个点 × 0.2 亩 × 199 元 ≈ 398 元/季。
这个数字很小，因为第一年我们只做示范、不追求收入。

成本侧，单点物料按 3 家询价中位数 210 元计；每亩投入约 1050 元，另加标定与复核人工
约 200 元/亩。要打平，需要死苗率下降带来的补苗节省与增产收益合计超过 1250 元/亩——
这是我们 2027 年春季要验证的核心数字，目前只能给区间，不能给结论。
```

为什么更好：
- 收入有乘法链条，读者可当场复算；
- 成本有来源（询价中位数）；
- 主动承认"打平需要什么"，而不是承诺盈利；
- 把不确定性写成"待验证的核心数字"，反而增加可信度。

## 3. 三条可复用的改写动作

| 动作 | 示例 |
|---|---|
| 删标签，改成句子 | `核心逻辑：硬件为入口` → `我们先靠设备把服务送进棚，再靠数据留住客户` |
| 每个形容词换成事实 | `显著提升效果` → `第 7 天活菌数提高 1.8 倍（n=3，待 P1 验证）` |
| 主动写边界 | `必将颠覆` → `只验证草莓；水稻、茶叶需另行试验` |
