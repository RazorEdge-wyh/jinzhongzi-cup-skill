# 写作风格规范：去 AI 感（Writing Style）

> 目标：让 agent 产出的材料读起来像**认真参赛的学生团队**写的，而不是像 AI 拼出来的。
> 依据：评审实测经验 + 现成中文 BP 技能（[sevonsss-plan](https://github.com/sevonsss/sevonsss-plan)）的写作纪律，结合本 skill 的"证据台账 + linter"机制。

## 1. 六条硬规则

### 规则 1：叙述体优先，禁用标签体

**坏**：

```
定位宣言：做设施草莓的根际守护者
核心逻辑：硬件为入口、数据为壁垒、服务为粘性
```

**好**：

```
我们做的事很简单：在草莓定植后的头 30 天，当土壤偏干、温度合适时，自动补一次小水。
农户不需要理解菌，只需要看到死苗少了、菌肥没白买。
```

理由：标签体（`XX：` + 短语）是 AI 文本最强的指纹；评委一眼能识别。

### 规则 2：段落为主，表格为辅

- 表格只用于**必须精确对齐**的内容：BOM、财务三表、竞品参数、评分维度对照。
- 每张表前要有过渡句："具体参数见下表""三年预测如下"。
- 观点、痛点、策略用段落叙述；不要用表格堆观点。

### 规则 3：正文零批注

写作过程标记（`[实测]/[估算]/[待补]`、`[核实 Sx]`、`【待填】`、`> 自检清单`、emoji、✅⚠️★）**提交版必须清掉**。

数据诚实性改由两处承担：
1. 文首"数据说明"一句话（哪些是实测、哪些是估算）；
2. 财务章"基本财务假设"小节（逐条列假设与来源）。

linter 会扫描批注残留：`check_annotation_leaks`。

### 规则 4：套话克制

- 对仗金句（"硬件为入口、订阅为粘性、机构方案为价值"）**全篇最多一处**。
- 禁用高频空词：闭环、赋能、双轮驱动、数据飞轮、生态化反、降维打击。
- "国际领先/填补空白/颠覆/国内首创"必须删掉或改为可证明的表述（有查新/专利才可写"首次"）。

### 规则 5：图表规范

- 图题在**图下方**，表题在**表上方**；图号按章编排（图 1-1、表 2-3）。
- 正文用"如图 1-1 所示"引导，不出现"下图""左表"。
- 每张图表都要在正文被解释一次（不是贴上去就完事）。

### 规则 6：语气与细节

- 像学生在陈述：具体（型号/数量/地点/时间/用户原声），不空。
- 少用营销腔（"颠覆行业""重新定义"），多用事实（"12 户莓农中 8 户愿意付 199 元/亩"）。
- 第一人称可用"我们"，但正式申报书字段用第三人称（"项目团队"）。

## 2. 数字写法

| 场景 | 写法 |
|---|---|
| 实测 | `第 7 天根际活菌数 3.2×10⁵ CFU/g 鲜土（n=3，均值±SD，2026-04，长沙 XX 合作社）` |
| 估算 | `按单点覆盖 0.2 亩测算，亩均投入约 1050 元（假设：单点成本 210 元、无补贴）` |
| 待补 | `死苗率下降幅度待 P1 田间试验测定（计划 2027-03，n=3 小区）` |
| 禁止 | `显著提升效果`（无数字）、`市场巨大`（无口径）、`预计将达到 30%`（把待补写成预计） |

## 3. 自检流程

1. 写完先自查 §1 六条（尤其规则 1、3）。
2. 跑 linter：`python scripts/check_submission.py <文件> --kind plan`
3. 看三类提示：
   - `空话/无证据最高级` → 删或改
   - `数字无来源` → 补来源或改估算/待补
   - `正文批注残留` / `标签体` → 清掉
4. 人工再读一遍：**每段是否有一个具体事实**？没有就删。

## 4. 反例集（评委最反感的 8 种写法）

1. 通篇"我们致力于……我们将打造……"（无主语、无动作）。
2. 每段都以"首先/其次/最后"开头（模板感）。
3. 用表格堆 20 行"优势/价值/意义"。
4. 把评审维度名直接当小标题（"产品创新与技术突破：我们很创新"）。
5. 大量"国内领先、填补空白"却没有任何检测/专利。
6. 财务预测只有结论数字，没有假设与推导。
7. 团队页只有头衔没有分工与投入。
8. 结尾"必将为中国农业现代化贡献力量"（空话）。

> 一句话：**让每一段都能被追问出证据，让每一句都不像模板。**
